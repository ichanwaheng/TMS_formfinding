## Hypar mesh visualization script

`hypar_fenicsx.py` builds a triangular FEniCSx mesh on a rectangle, warps it
into a hyperbolic paraboloid (hypar), and exports an interactive Plotly view.

### Run

```bash
python hypar_fenicsx.py
```

Output:

- `hypar_fenicsx.html` (interactive 3D visualization)
